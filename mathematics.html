Mathematics

Clear notes with worked examples, practice exercises and revision tips covering the core of secondary-school Mathematics.

Printable copy: Download Mathematics notes + exercises (PDF)

1. Algebra and equations

Whatever you do to one side of an equation, do to the other. Expand brackets first, collect like terms, then isolate the unknown.

Worked examples
Solve 3x − 7 = 11: 3x = 18, so x = 6.
Solve 5(x − 2) = 3x + 4: 5x − 10 = 3x + 4, so 2x = 14 and x = 7.
Simultaneous equations (elimination): 2x + y = 7 and x − y = 2. Adding: 3x = 9, so x = 3; then y = 1. Check: 2(3) + 1 = 7 ✓.

2. Quadratic equations

Standard form ax² + bx + c = 0. Quadratic formula: x = (−b ± √(b² − 4ac)) / 2a. The discriminant b² − 4ac tells you: > 0 two real roots, = 0 one repeated root, < 0 no real roots.
Worked examples
Factorise: x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or x = 3.
Formula: 2x² + 3x − 5 = 0 → x = (−3 ± √(9 + 40))/4 = (−3 ± 7)/4 → x = 1 or x = −2.5.

3. Indices and logarithms

aᵐ × aⁿ = aᵐ⁺ⁿ   aᵐ ÷ aⁿ = aᵐ⁻ⁿ   (aᵐ)ⁿ = aᵐⁿ   a⁰ = 1   a⁻ⁿ = 1/aⁿ
loga x = y means aʸ = x   log(xy) = log x + log y   log(x/y) = log x − log y   log xⁿ = n log x
Worked examples
2³ × 2⁴ = 2⁷ = 128.   log₂ 32 = 5 (since 2⁵ = 32).   log₁₀ 1000 = 3.
Solve 3ˣ = 81: 81 = 3⁴, so x = 4.

4. Geometry and trigonometry

Pythagoras: a² + b² = c²   sin θ = opp/hyp   cos θ = adj/hyp   tan θ = opp/adj (SOH-CAH-TOA)
Circle: area = πr², circumference = 2πr. Triangle area = ½ × base × height. Angles in a triangle add to 180°.
Worked example
Right-angled triangle with shorter sides 5 and 12: hypotenuse = √(25 + 144) = 13. A tree is seen at 30° from 50 m away: height = 50 × tan 30° = 28.9 m.

5. Statistics and probability

Mean = sum ÷ number   Median = middle value when ordered   Mode = most frequent   Range = max − min
P(event) = favourable outcomes ÷ total outcomes. Independent events: P(A and B) = P(A) × P(B).
Worked examples
Data 4, 7, 7, 9, 13: mean = 40/5 = 8, median = 7, mode = 7, range = 9.
Two dice: P(total 7) = 6/36 = 1/6.
A bag has 3 red and 5 blue balls. Two are drawn without replacement: P(both red) = 3/8 × 2/7 = 6/56 = 3/28.

6. Sequences and series

Arithmetic: Tₙ = a + (n − 1)d,   Sₙ = n/2 [2a + (n − 1)d]
Geometric: Tₙ = arⁿ⁻¹,   Sₙ = a(rⁿ − 1)/(r − 1)
Worked examples
AP with a = 3, d = 4: T₁₀ = 3 + 9 × 4 = 39; S₁₀ = 5 × (3 + 39) = 210.
GP with a = 2, r = 3: T₅ = 2 × 3⁴ = 162; S₅ = 2(3⁵ − 1)/2 = 242.

7. Introduction to calculus

d/dx (xⁿ) = nxⁿ⁻¹   ∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C   (n ≠ −1)
Stationary points occur where dy/dx = 0. Definite integrals give the area under a curve.
Worked examples
Differentiate y = 3x⁴ − 2x² + 5x: dy/dx = 12x³ − 4x + 5.
Integrate (6x² + 4): 2x³ + 4x + C. Evaluate ∫₀² 3x² dx = [x³]₀² = 8.
Turning point of y = x² − 6x + 5: dy/dx = 2x − 6 = 0 → x = 3, y = −4. Since d²y/dx² = 2 > 0, it is a minimum.

8. Exercises with answers

  1. Solve 5(x − 2) = 3x + 4.
    Answer5x − 10 = 3x + 4 → 2x = 14 → x = 7.
  2. Factorise x² + x − 12 and solve x² + x − 12 = 0.
    Answer(x + 4)(x − 3) = 0 → x = −4 or x = 3.
  3. Solve x² − 4x − 1 = 0, leaving surds.
    Answerx = (4 ± √20)/2 = 2 ± √5 (≈ 4.24 or −0.24).
  4. Solve 3x + 2y = 16 and x − y = 2.
    Answerx = y + 2 → 3y + 6 + 2y = 16 → y = 2, x = 4.
  5. A right-angled triangle has shorter sides 8 cm and 15 cm. Find the hypotenuse.
    Answer√(64 + 225) = √289 = 17 cm.
  6. The mean of six numbers is 12. Five of them add up to 58. Find the sixth.
    AnswerTotal = 72, so sixth = 72 − 58 = 14.
  7. A bag has 3 red and 5 blue balls. Two are drawn without replacement. Find P(both red).
    Answer3/8 × 2/7 = 3/28.
  8. Find the stationary points of y = x³ − 3x².
    Answerdy/dx = 3x² − 6x = 3x(x − 2) = 0 → x = 0 (y = 0) and x = 2 (y = −4).

9. Revision tips

  • Practise a little every day rather than a lot the night before. Redo questions you got wrong after a few days.
  • Show every step; method marks reward working. Check by substituting your answer back.
  • Learn the formula list above until you can write it from memory, then use past-paper-style questions under timed conditions.
